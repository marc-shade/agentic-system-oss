# Browser Automation

Automate web browser interactions.

## Usage
Browser MCP: `mcp__browsermcp__browser_*`
Puppeteer: `mcp__puppeteer__puppeteer_*`

## Operations
- **navigate**: Go to URL
- **click**: Click elements
- **type**: Enter text
- **screenshot**: Capture page
- **snapshot**: Get page structure

## Examples
"Navigate to example.com and take screenshot"
"Click the login button and fill username"
"Get all links from the page"

## Features
- Headless or visible browser
- Wait for elements
- Form automation
