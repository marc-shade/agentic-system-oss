# Parallel Task Execution

Run multiple AI agents in parallel for complex tasks.

## Usage
Use multiple Task tools simultaneously for parallel execution.

## Pattern
```
Task(description="Approach 1", prompt="Conservative solution")
Task(description="Approach 2", prompt="Innovative solution")
Task(description="Approach 3", prompt="Performance-focused")
```

## Best For
- Feature implementations with multiple approaches
- Research requiring different perspectives
- Complex refactoring projects
- Competitive analysis
- Multi-agent workflows

## Example
"Implement user auth with 3 different approaches"
"Research competitors from multiple angles"
