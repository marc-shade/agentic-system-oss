AI image generation using multiple providers and techniques.

Usage:
- /user:image-generation create "cyberpunk cityscape" - Generate image with FLUX
- /user:image-generation flux "portrait of scientist" size:1024x1024 - FLUX generation
- /user:image-generation sdxl "fantasy landscape" - SDXL generation
- /user:image-generation prompt "modern office space" - Generate optimized prompt
- /user:image-generation style "watercolor painting of mountains" - Style transfer
- /user:image-generation batch "logo designs" count:4 - Multiple variations
- /user:image-generation upscale "low_res_image.jpg" - Image enhancement

Example: /user:image-generation create "professional headshot, business attire, studio lighting" size:512x512
