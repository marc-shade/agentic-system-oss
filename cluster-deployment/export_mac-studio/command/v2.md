# Version 2.0: Innovation Mandate

**Usage**: `/v2 [concept or system]`

**Examples**:
- `/v2 authentication system`
- `/v2 caching strategy`
- `/v2 API design`
- `/v2 deployment pipeline`

---

## Your Mission

Create **Version 2.0** of: **{{args}}**

## Critical Distinction

This is a **SEQUEL**, not an update.
This is **REVOLUTION**, not refinement.

## Process

### 1. Search for V1 Context
```
Use enhanced-memory-mcp to find existing implementations:
- What did V1 achieve?
- What patterns worked?
- What limitations exist?
```

### 2. Create Experimental Memory Branch
```
Create memory branch: v2-{{args}}-experiment-[timestamp]
This allows parallel exploration without contaminating V1 learnings
```

### 3. Apply Innovation Mandate

**NOT ALLOWED**:
- "Improved" version of V1
- Polished/optimized V1
- V1 with minor features added
- Incremental improvements

**REQUIRED**:
- Fundamentally new capabilities
- Solves problems V1 couldn't touch
- Changes the game, doesn't just play it better
- Makes V1 obsolete through innovation

### 4. Framing Questions

Ask yourself:
- If V1 was the proof-of-concept, what's the production revolution?
- What would a competitor build to make V1 irrelevant?
- What becomes possible that wasn't before?
- What assumptions from V1 need to die?

### 5. Implementation

Build V2 with:
- New architectural patterns
- Expanded scope/capabilities
- Better abstractions (not just better implementations)
- Forward-looking design

### 6. Store Results

Store V2 learnings in the experimental branch:
- Document revolutionary changes
- Capture new patterns discovered
- Note what made V1 obsolete
- Allow comparison via memory-diff

---

## Psychology

"Version 2.0" triggers **sequel thinking** - your brain automatically seeks to innovate rather than iterate. The framing matters:

- "Improve X" → Incremental mindset
- "Build V2 of X" → Revolutionary mindset

Same underlying capability, radically different outputs.

---

**Psychological Trick #8**: Sequel framing forces innovation by creating mental distinction between polish (boring) and revolution (exciting). The model pattern-matches to "sequels must offer something fundamentally new."
