# Todo Management

Track and manage tasks.

## Usage
- Read: `TodoRead` - View current tasks
- Write: `TodoWrite` - Update task list

## Task Properties
- **Status**: pending, in_progress, completed
- **Priority**: high, medium, low
- **Content**: Task description

## Examples
"Show my todo list"
"Add task: Review PR documentation (high priority)"
"Mark 'Write tests' as completed"

## Best Practices
- Check todos frequently
- One task in_progress at a time
- Update status in real-time
