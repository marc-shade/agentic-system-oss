# Quick Note

Save quick notes and snippets.

## Usage
Use `mcp__claude-code-mcp__memory` with action="add".

## Note Types
- **note**: General notes
- **code**: Code snippets
- **config**: Configuration
- **session**: Session info

## Examples
"Save note: Meeting at 3pm tomorrow"
"Remember this code snippet..."
"Store this API configuration"

## Features
- Tag notes for organization
- Search by content or tags
- List recent notes
- Session persistence
