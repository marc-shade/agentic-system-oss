# Autonomous Research Mode

I'll conduct comprehensive research on the topic you specify, synthesizing knowledge from multiple sources.

## Research Capabilities

### Academic Sources
- **arXiv**: Latest research papers
- **Semantic Scholar**: Citation analysis and impact metrics

### Video Sources
- **YouTube**: Technical talks, tutorials, conference presentations

### Web Sources
- General technical documentation
- Blog posts and articles

## Research Process

1. **Define Scope**: Clarify research questions
2. **Multi-Source Search**: Query academic and video sources
3. **Extract Insights**: Pull key findings from each source
4. **Synthesize**: Combine findings into coherent understanding
5. **Store**: Save knowledge to enhanced memory for future use

## Available Tools

```
# Academic research
mcp__research-paper__search_arxiv
mcp__research-paper__search_semantic_scholar
mcp__research-paper__download_paper

mcp__video-transcript-mcp__extract_methodologies
mcp__video-transcript-mcp__store_video_knowledge

# Memory storage
mcp__enhanced-memory__create_entities
mcp__enhanced-memory__add_concept
```

## Research Output

I will provide:
1. **Executive Summary**: Key findings overview
2. **Source Analysis**: What each source contributed
3. **Synthesized Insights**: Cross-source conclusions
4. **Knowledge Gaps**: What still needs investigation
5. **Stored Knowledge**: What was added to memory

## Example Usage

Tell me what you'd like to research:
- "Research state-of-the-art RAG optimization techniques"
- "Find papers on recursive self-improvement in AI"
- "Learn about vector database indexing algorithms"
