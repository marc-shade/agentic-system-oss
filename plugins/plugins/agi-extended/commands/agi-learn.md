# Knowledge Learning Mode

I'll extract and store knowledge from the sources you provide.

## Learning Sources

### Research Papers
Provide arXiv IDs or search terms:
```
"Learn from arXiv paper 2301.12345"
"Learn about transformers from recent papers"
```

### YouTube Videos
Provide video URLs:
```
"Learn from https://youtube.com/watch?v=..."
"Extract knowledge from this AI talk"
```

### Codebase
Learn patterns from code:
```
"Learn the patterns in src/components/"
"Analyze and remember the architecture"
```

## Learning Process

1. **Extract**: Pull content from source
2. **Analyze**: Identify key concepts, techniques, insights
3. **Structure**: Organize into semantic categories
4. **Store**: Save to enhanced memory with proper tagging
5. **Link**: Connect to related existing knowledge

## Memory Types

### Semantic Memory
Timeless concepts and principles:
- Definitions
- Theories
- Best practices

### Procedural Memory
How-to knowledge:
- Techniques
- Methodologies
- Workflows

### Episodic Memory
Specific experiences:
- Paper summaries
- Video insights
- Code patterns
