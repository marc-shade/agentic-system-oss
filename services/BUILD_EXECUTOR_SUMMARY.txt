Submit Build (Python):
import redis, json, uuid

r = redis.Redis(host='localhost', port=6379, db=2)
job = {
    "build_id": str(uuid.uuid4()),
    "project_id": "my-app",
    "build_command": "npm install && npm run build",
    "build_env": "node:20",
    "timeout_seconds": 3600
}
r.lpush("build_queue", json.dumps(job))

TROUBLESHOOTING
-------------------------------------------------------------------------------

Executor won't start:
  $ docker info                     # Check Docker
  $ redis-cli -n 2 PING            # Check Redis
  $ tail -f logs/build_executor.log # Check logs

Builds not executing:
  $ redis-cli -n 2 LLEN build_queue            # Check queue
  $ redis-cli -n 2 KEYS "build:*:status"       # Check active
  $ ./build-executor-daemon.sh status          # Check worker

Webhook failures:
  $ tail -f logs/webhooks.log       # Check delivery log
  $ curl -X POST http://host/callback # Test endpoint

Docker issues:
  $ docker ps                       # List containers
  $ docker logs build-{id}          # Check container logs
  $ docker system prune             # Clean up
